# Remix: نظام إدارة المحل والمخزون (دليل التشغيل المحلي)

هذا المشروع مبني باستخدام **React** و **Vite** و **Tailwind CSS**. عند تحميل المشروع كحزمة مضغوطة (ZIP) وتشغيله محلياً، هناك خطوات بسيطة يجب اتباعها ليتم تشغيل التطبيق بنجاح.

---

## ⚠️ لماذا لا يعمل التطبيق بمجرد الضغط المزدوج على `index.html`؟
عند فتح ملف `index.html` مباشرة في المتصفح (عبر بروتوكول `file://`)، ستحصل على **صفحة بيضاء فارغة** ولن يظهر أي شيء.
* **السبب:** يعتمد نظام React و Vite الحديث على ميزة تسمى "بروتوكول وحدات JavaScript" (ES Modules). تمنع متصفحات الإنترنت (مثل Chrome و Chrome Edge و Firefox) تحميل هذه الملفات مباشرة من جهازك لأسباب أمنية (سياسة CORS).
* **الحل:** يجب تشغيل التطبيق من خلال بيئة تطوير محلية (Local Server) كما هو موضح أدناه.

---

## 🛠️ خطوات التشغيل خطوة بخطوة

### الخطوة 1: تثبيت برنامج Node.js (إذا لم يكن لديك)
يعتبر Node.js البرنامج الأساسي لتشغيل وإدارة مشاريع الويب الحديثة.
1. اذهب إلى الموقع الرسمي: [https://nodejs.org/](https://nodejs.org/)
2. قم بتحميل نسخة **LTS** (النسخة الموصى بها لمعظم المستخدمين).
3. قم بتثبيت البرنامج على جهازك باتباع الخطوات التقليدية (Next -> Next -> Finish).

---

### الخطوة 2: فك ضغط الملف وتحضير المشروع
1. قم بفك ضغط الملف الذي قمت بتحميله في مجلد مخصص على جهازك.
2. افتح نافذة الأوامر (Terminal أو Command Prompt):
   * **على Windows:** افتح المجلد الذي قمت بفك الضغط فيه، ثم في شريط مسار الملفات بالأعلى اكتب `cmd` واضغط Enter.
   * **على Mac/Linux:** افتح تطبيق الـ Terminal واستخدم الأمر `cd` للوصول لمجلد المشروع (مثال: `cd path/to/project`).

---

### الخطوة 3: تثبيت المكتبات (Dependencies)
في نافذة الأوامر التي فتحتها، اكتب الأمر التالي واضغط Enter:
```bash
npm install
```
*سيقوم هذا الأمر بتحميل كافة المكتبات والملفات اللازمة للمشروع (مثل React و Tailwind و Lucide Icons) وتخزينها في مجلد يسمى `node_modules`.*

---

### الخطوة 4: تشغيل التطبيق
بعد اكتمال التثبيت، اكتب الأمر التالي لتشغيل خادم التطبيق المحلي:
```bash
npm run dev
```

ستظهر لك رسالة تفيد بأن التطبيق يعمل محلياً، تشبه هذه:
```text
  VITE v6.2.3  ready in 300 ms

  ➜  Local:   http://localhost:3000/
  ➜  Network: http://192.168.1.10:3000/
```

---

### الخطوة 5: فتح التطبيق في المتصفح
الآن، افتح متصفح الإنترنت الخاص بك (Chrome أو Edge أو Safari) واذهب إلى الرابط التالي:
[http://localhost:3000](http://localhost:3000)

🎉 مبروك! سيعمل نظام إدارة المحل والمخزون بالكامل وبشكل سريع جداً.

---

## 💡 نصائح إضافية وحل المشكلات

* **منفذ التشغيل (Port):** بشكل افتراضي، تم تهيئة المشروع ليعمل على المنفذ `3000`. إذا كان هذا المنفذ مستخدماً من قبل برنامج آخر على جهازك، فسيقوم Vite تلقائياً بعرض خيار لتشغيله على منفذ آخر (مثال: `3001`). تابع الروابط التي تظهر في نافذة الأوامر.
* **إغلاق التطبيق:** لإيقاف تشغيل الخادم المحلي في أي وقت، اضغط على زر `Ctrl + C` في نافذة الأوامر ثم اكتب `Y` واضغط Enter.
* **حفظ البيانات:** يستخدم التطبيق الذاكرة المحلية للمتصفح (`localStorage`) لحفظ بيانات المنتجات، المبيعات والصيانة. هذا يعني أن بياناتك لن تضيع حتى لو قمت بإغلاق المتصفح أو إعادة تشغيل الجهاز!
